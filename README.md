### 1. Загрузка и подготовка типов
Задание структурированного типа `np.dtype` для эффективного чтения CSV-файла. Оценка занимаемой памяти и базовая проверка на наличие `NaN`/`Inf` значений.

```python
dt = np.dtype([
    ('ts', 'i4'), ('acc_id', 'i2'), ('likes', 'u4'),
    ('shares', 'u2'), ('com', 'u2'), ('sent', 'f4')
])

```

Поиск аномалий лайков внутри каждой группы по методу межквартильного размаха (1.5×IQR) и их замена на медиану группы.

